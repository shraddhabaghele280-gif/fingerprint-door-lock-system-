# Fingerprint Based Door Lock System

## Description
Fingerprint-based door lock system using Arduino for secure biometric access.

## Components
- Arduino Uno  
- Fingerprint Sensor  
- Servo Motor / Relay  
- Buzzer  
- Jumper Wires  

##  Working
The system scans the fingerprint and matches it with stored data.  
If matched, the door unlocks. Otherwise, access is denied.

##  Fingerprintprint
- Authorized → Door Description
- Unauthorized → Access denied
